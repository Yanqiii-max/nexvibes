# NexVibes · AI 课程平台 Demo

纯静态网站（HTML + CSS + 原生 JS），无需构建，可直接部署到 GitHub Pages / 任何静态托管。

## 本地打开

YouTube 视频不能在“双击打开的本地文件”里播放，请用本地服务器：

```bash
cd nexvibes && python3 -m http.server 8153   # 浏览器访问 http://localhost:8153
```

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 页面骨架 |
| `css/style.css` | 全部样式（品牌紫 #5541DC + 薄荷绿 #5FD9B0） |
| `js/data.js` | **所有内容都在这里改**：课程、课时视频、讲座、文章、工具库、合作院校、演示账号 |
| `js/app.js` | 路由、播放器、作业/评分/成绩册、三种身份的主页 |
| `assets/` | Logo（透明底 + 白色版）、favicon |

## 加内容

- **加一节课**：在 `data.js` 对应课程的 `lessons` 里加一项。视频写 `src: { t: 'yt', id: 'YouTube视频ID' }` 或 `src: { t: 'bili', id: 'BV号' }`；自己录的课还没上传就写 `src: { t: 'own' }`，页面会显示“录制中”占位窗口。
- **老师在网页里挂视频**：以教师身份进入任意“NexVibes 原创”课时，粘贴 YouTube / B 站链接即可（演示版保存在本浏览器）。
- 所有文字字段都是 `{ en: '…', zh: '…' }` 双语。

## 演示说明

- 登录页可选学生 / 教师 / 学校管理员三种身份，无需密码。
- 作业提交、评分、公告、直播课排期都保存在浏览器 localStorage；用户菜单里“重置演示数据”可恢复初始状态。
- 学生作品展、管理端统计数字为示意数据，页面上已标注。
